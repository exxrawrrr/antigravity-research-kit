# Antigravity Research Kit v0.1.0

First public usable release of **Antigravity setup + Rafdi Academic Research Pack**.

Made by **Rafdi D. Ulhaq / @exxrawrrr**.

## Included
- Antigravity 2.x detection/install through official WinGet package ID.
- Antigravity IDE detection/install.
- Antigravity CLI (`agy`) detection/install.
- Tokyo Night extension + Tokyo Night Storm selection.
- Material Icon Theme.
- Permission-first defaults and terminal sandbox support.
- `agy-safe` launcher.
- Rafdi Academic Research Pack with 5 lazy-loaded skills:
  - Research
  - Document
  - Reviewer
  - Document Style Learning
  - Evidence Tracing
- Beginner launchers: `INSTALL.bat`, `VERIFY.bat`, `REPAIR.bat`, and managed rollback.
- SHA256 manifest inside the release package plus a SHA256 file for the ZIP.

## Install
1. Download `Antigravity-Research-Kit-v0.1.0.zip`.
2. Verify the SHA256 file if desired.
3. Extract the ZIP completely.
4. Double-click `INSTALL.bat`.
5. Do not close the terminal until it reports completion.
6. Complete any official Antigravity/Google sign-in yourself.
7. Run `VERIFY.bat`.

The installer never copies login credentials, OAuth tokens, cookies, or API keys from another machine.
