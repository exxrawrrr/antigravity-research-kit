# Document Style Learning

**Made by Rafdi D. Ulhaq**

Extract a reusable formatting profile from a reference document without copying its academic content.

## Procedure

1. Inspect the reference file in a non-destructive way.
2. Sample enough pages/sections to distinguish intentional rules from one-off formatting.
3. Record observed values and confidence.
4. Mark unknown values as unknown instead of inventing them.
5. If an official written guideline is available, compare it with the sample and record conflicts.
6. Save a project-local profile when file access allows it.

## Profile fields

Capture when observable:
- page size and orientation;
- top/right/bottom/left margins;
- body font family and size;
- body alignment;
- line spacing;
- paragraph spacing before/after;
- first-line or hanging indent;
- chapter title style;
- heading levels;
- numbering pattern;
- table style;
- figure/caption style;
- footnote/endnote style;
- page-number location and section behavior;
- bibliography/reference layout;
- header/footer conventions.

## Suggested profile file

Use a project-local file such as:

`.rafdi-research/document-profile.json`

Include:
- source filename;
- extraction timestamp;
- observed rules;
- confidence per rule;
- conflicts with official guidance;
- unresolved/unknown items.

## Verification

Test the derived profile on a small target section first. Compare the rendered result with the reference before applying it to a full manuscript.

A sample document is evidence of formatting practice, not automatic proof of official institutional policy.
