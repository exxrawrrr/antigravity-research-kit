# Evidence Tracing

**Made by Rafdi D. Ulhaq**

Keep research findings traceable from claim back to source.

## Ledger fields

For each evidence item, capture only what is actually known:
- short source ID;
- full title;
- author/editor/organization;
- year;
- source type;
- publisher/journal/institution;
- DOI, ISBN, stable URL, or database identifier;
- page/section only when verified;
- claim supported;
- evidence note or concise paraphrase;
- direct quotation only when necessary and accurately copied;
- relevance to the user's research;
- limitations or population/context caveats;
- verification status.

## Rules

- Never invent missing metadata.
- Do not convert a search-result snippet into a verified quotation.
- Keep primary-source links when a secondary source merely summarizes them.
- If two credible sources disagree, record the disagreement instead of flattening it into false certainty.
- For web sources, record access date when appropriate.
- Use citation style requested by the user/institution only after bibliographic data is verified.

## Output

Prefer a project-local ledger such as `.rafdi-research/evidence-ledger.md` or a structured table/CSV when many sources are involved.

The ledger supports writing; it does not replace reading the underlying source.
